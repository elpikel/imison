# Decision log

Dated decision log: what, why, what was rejected.

- 2026-11-11: Claude kit set up (copied from ether). Repo is a plain Mix library, not a Phoenix app; web and DB rows in `.claude/project.md` point at the host app and the future `dev/` app.
- 2026-11-11: Design adopted from "Imision: architecture and user stories" (`docs/PROJECT.md`). Name is Imision: renamed the `mix new` skeleton from `Imison`/`:imison`. ADRs 0001–0003 accepted; 0004 (built-in login) and 0005 (no hard Oban dependency) proposed until the open decisions are settled.
- 2026-11-11: Tooling: Styler formatter plugin, Credo `--strict` with the ExSlop plugin.
- 2026-11-11: Work tracking: no issue tracker; plans and tasks live in `.claude/work/<slug>/`; `/implement` needs a feature branch off `main`.
- 2026-11-11: Dashboard design added as static mockups in `docs/design/` (`app.css` + one HTML page per screen). LiveViews reuse its markup and class names. `app.css` moved to `priv/static/app.css`, the shipped asset, and the mockups link to it.
- 2026-11-11: Fonts bundled instead of loaded from Google Fonts, so host apps' dashboards make no third-party requests and pass strict CSP. Instrument Sans (variable, 400–700) and JetBrains Mono (400, 600), latin + latin-ext WOFF2 from Fontsource 5.3.0, in `priv/static/fonts/` with their OFL 1.1 licenses, which the OFL requires when redistributing. Rejected: system font stack (loses the design's look).
- 2026-11-11: Backlog in `docs/STORIES.md`: the design's 36 stories with IDs, build order, dependencies and "done when" lines, plus DEV-01 (test database) and DEV-02 (`dev/` host app) as setup. Replaces the story table in `PROJECT.md` so there is one list.
- 2026-11-11: `mix check` alias runs in the test env: `compile --warnings-as-errors --force`, `deps.unlock --check-unused`, `format --check-formatted` (Styler), `credo --strict` (ExSlop), `test`. It stops at the first failure.
- 2026-11-11: Test database (DEV-01): `mix test` runs the standard alias `ecto.create` + `ecto.migrate` on `imision_test`, never drops it. After editing an unreleased `Imision.Migration` version, reset by hand with `MIX_ENV=test mix ecto.reset`. Rejected: dropping and recreating on every run; migrating from `test_helper.exs` with `Ecto.Migrator`. Wrapper migrations live in `test/support/postgres/migrations/` (test repo `priv:`), outside the package, one per released version, as a host app does.
- 2026-11-11: `Imision.Migration` added as a stub in DEV-01: `up/1` and `down/1` are no-ops, so the test repo's wrapper migration goes through it now and INS-02 only adds version 1. Rejected: leaving the wrapper migration empty until INS-02 (misses DEV-01's "done when").
- 2026-11-11: `ecto_sql ~> 3.14` and `postgrex ~> 0.22` added as required dependencies now: they were already planned runtime deps in `docs/PROJECT.md`, and the test repo needs them. Rejected: `optional: true` (Imision's migration and schemas always need them, as Oban's do).
- 2026-11-11: Tests cover Imision's behaviour only: no tests of framework behaviour (Ecto's SQL sandbox or migrator) or of no-op stubs. DEV-01 adds no tests of its own: `mix test` going green through the `ecto.create` + `ecto.migrate` alias is the check, and sandbox isolation, test-only compilation and the wrapper migration running were checked once by hand. Real database tests arrive with INS-02, which uses `Imision.DataCase`.
- 2026-11-11: Development host app (DEV-02): `dev/` is a gitignored, local-only Mix project with a path dependency on Imision (user's choice: not pushed to the repo), so the library's `mix.exs` and deps are unchanged and `dev/` can't enter the Hex package. Built by hand: endpoint, router, one controller with sample error routes and an error view; `mix dev` creates and migrates `imision_dev` and starts the server. Errors render as plain text (no `phoenix_html`). Checked by hand, no tests. Rejected: a `dev.exs` script with `only: :dev` deps in the library's `mix.exs` (dev-only code and deps in the repo); a committed `dev/` project; `phx.new` (assets and generators the app doesn't need).
